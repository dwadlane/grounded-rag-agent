# Telehealth Technical Help

## Before the Call

Use the latest version of Chrome, Safari or Edge and allow camera and microphone access. You can run a test call at harbourside.example/test.

## If the Call Drops

Rejoin with the same link. If you have not reconnected within 5 minutes, the clinician phones you.

## Privacy on Calls

Choose a private room for your call. We never record telehealth calls.
